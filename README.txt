THE RECIPE CORNER — BEGINNER HTML/CSS WEBSITE

FILES
- index.html: homepage and category dropdown
- style.css: shared styling
- categories/: five category pages
- recipes/: fifty individual recipe pages

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the folders and files together in the same structure.
3. Open index.html in a browser.
4. Click a category card to see its ten recipes.
5. Click View recipe to open a separate HTML page for that recipe.

NO JAVASCRIPT
The site uses only HTML and CSS. The category dropdown uses a CSS checkbox and a full-page label overlay. Clicking outside the open menu closes it. Each recipe is a separate HTML page connected with hyperlinks.

IMAGES
Images load from Unsplash, so an internet connection is needed to display them.

EDITING
- Change colours and layout in style.css.
- Change homepage text in index.html.
- Each recipe has its own file in recipes/.
- Each category listing is in categories/.
